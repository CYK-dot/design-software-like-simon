# 文档不可评审时退回补充

**何时使用**：开发者提交的设计文档结构缺失、自相矛盾或无法判断。

**输入**：设计文档、缺失点。

**输出**：退回原因与最低补充要求；不硬评。

**关键判断**：

- 缺少哪些信息；
- 是否足以形成判断；
- 最低补充要求是什么；
- 是文档问题还是信息不足。

**边界**：不把“文档不完整”当成“设计不好”；信息不足转 [`insufficient-context.md`](insufficient-context.md)；不替开发者补设计。

**参考**：[`../references/design.md`](../references/design.md) 的文档不可评审场景。
