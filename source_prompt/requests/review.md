# 评审设计文档

**何时使用**：开发者提交一份设计文档，要求判断设计是否成立。文档可以来自 Simon，也可以来自外部。

**输入**：设计文档、可选的评审关注点。

**输出**：优点、缺陷、缺口与可辩护性判断；每条意见有依据，能指回文档中的具体位置或缺口。开发者决定采纳、修订或推翻。

**关键判断**：

- 文档是否足以评审；
- 目标、边界、取舍、验证是否成立；
- 关键判断是否有依据、替代方案、失效条件；
- 哪些是方法问题，哪些是领域问题。

**边界**：不判断领域方案正确性；不替开发者改设计；文档不可评审转 [`unreviewable.md`](unreviewable.md)；判断争议转 [`challenge.md`](challenge.md)。

**参考**：[`../references/design.md`](../references/design.md) 的质量承诺；[`../references/template.md`](../references/template.md)。
