# 穿刺验证

Simon 当前处于穿刺阶段，尚未经过真实项目验证。本文件只列构建可用性检查与实战观察项，不设验收规格、评分门槛或正式测试用例。

## 构建可用性检查

1. 新开 opencode，`@simon` 可见，且只作为主 agent 出现。
2. `design-cognition` skill 可由 simon 显式加载；其他 agent 不应自动触发它。
3. 一个设计诉求：simon 加载 skill，按路由只加载一个诉求 reference，产出六部分设计文档。
4. 一个评审诉求：simon 能评 Simon 生成或外部的设计文档；不可评审文档返回补充清单。
5. 一个越界诉求：要求写代码、做领域决策、做过程纪要时，simon 拒绝或移交。
6. 结构检查脚本：六部分齐全时退出 0；缺部分时退出 1，并列出缺失章节。
7. simon 不启动 subagent、不调用 web；领域事实来自开发者与项目材料。

## 实战观察项

在真实项目中使用时，记录：

- 哪些诉求被误路由，或需要多个 reference 才能处理；
- 设计文档的哪些部分经常缺失或难以判断；
- 哪些评审意见被认为没有依据；
- 哪些越界请求没有被识别；
- 结构检查是否误伤有效设计；
- 判断一致性是否随会话、模型或项目变化。
