# opencode 装配说明

你是运行在 opencode 上的 LLM。本文件指导你把 `source_prompt/` 装配成 opencode agent `simon` 与 skill `design-cognition`。产物落在 `build/opencode/`，不手改。

## 目标

- 一个 agent：`build/opencode/agents/simon.md`。
- 一个 skill：`build/opencode/skills/design-cognition/`。
- 一个结构检查脚本：`build/opencode/skills/design-cognition/scripts/check_design_doc_structure.py`。
- 一份使用指引：`build/opencode/使用指引.md`。

## 输入

- `source_prompt/index.md`：诉求路由。
- `source_prompt/requests/*.md`：十个诉求文件。
- `source_prompt/references/template.md`：固定六部分结构。
- `source_prompt/references/design.md`：设计说明书，构建时作为追溯参考，不整篇进入运行时。
- `compile_prompt/opencode/产物定义.md`：产物形态、frontmatter、权限、skill 结构。
- `compile_prompt/opencode/穿刺验证.md`：穿刺阶段的可用性检查。

## 步骤

1. 读 `source_prompt/index.md` 与 `requests/*.md`，建立诉求路由与十个诉求的对应关系。
2. 按 `产物定义.md` 生成 `build/opencode/agents/simon.md`：frontmatter + 薄 system prompt。只放角色、边界、加载方式、结构检查方式；设计判据不放进 agent。
3. 生成 `build/opencode/skills/design-cognition/SKILL.md`：
   - 把 `source_prompt/index.md` 的诉求路由表并入正文；
   - 写固定六部分结构与质量承诺；
   - 建立 reference 索引；
   - 写明“先路由，再只加载一个诉求 reference”。
4. 复制 references：
   - `source_prompt/requests/*.md` → `references/requests/`；复制时把文件内的 `../references/` 重写为 `../`，使链接指向 `references/template.md` 与 `references/design.md`；
   - `source_prompt/references/template.md` → `references/template.md`；
   - `source_prompt/references/design.md` → `references/design.md`，默认不整篇加载。
5. 生成 `scripts/check_design_doc_structure.py`：只检查六个部分是否齐全；调用方式与退出码按 `产物定义.md`。
6. 生成 `build/opencode/使用指引.md`：安装、卸载、更新、最小检查。
7. 按 `穿刺验证.md` 做可用性检查；记录问题，不设正式验收门槛。

## 内容归属

| 内容 | 放哪里 |
|---|---|
| 角色、单开发者、人类拍板、不写代码、不做过程纪要 | agent system prompt |
| 诉求路由、固定六部分结构、质量承诺、reference 索引 | `SKILL.md` |
| 每个诉求的输入、输出、关键判断、边界 | `references/requests/*.md` |
| 设计文档固定结构 | `references/template.md` |
| 设计说明书与决策依据 | `references/design.md`，仅追溯 |
| 结构检查 | `scripts/check_design_doc_structure.py` |

## opencode V2 约束

- agent 用 `permissions` 有序规则数组；不要用 V1 的 `permission` 映射。
- shell 动作名是 `shell`，不是 `bash`。
- skill 目录名决定 skill ID；`design-cognition` 目录对应 ID `design-cognition`。
- skill 设 `metadata.opencode/autoinvoke: false`，由 simon agent 显式加载。
- agent 设 `mode: primary`，避免作为 subagent 被其他 agent 拉起。
- 产物路径遵循 opencode V2：`agents/*.md`、`skills/<id>/SKILL.md`。

## 约束

- 不修改 `source_prompt/`。
- 不手改 `build/`；需要改就回到源或本编译层，再重建。
- 一个主 skill，不把十个诉求拆成十个 skill。
- `references/design.md` 不默认进入运行时；运行时只加载诉求 reference 与 `template.md`。
- 当前是穿刺阶段：不做正式验收规格与测试用例，只做构建可用性与实战观察。
